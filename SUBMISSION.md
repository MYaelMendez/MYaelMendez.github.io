## What it demonstrates

### Usefulness

New business owners need more than chatbot answers. They need a guided operational context: identity, storefront, payments, entity formation, agent roster, and deployment surface.

`>_æ:#startabusiness→` turns that into a Hermes skill and an `agentic.html` viewport.

### Viability

- The skill is a single installable `SKILL.md`.
- The HTML viewport is static and deployable anywhere: GitHub Pages, Hostinger, Workers, or æ.store.
- `domain-stack.json` encodes each owned domain as a skill in a compact Code Mode registry.
- The Stripe / DAOLLC flows are routed through user-controlled links rather than unsafe credential handling.
- Reachy Clerk is framed as the embodied app/storefront operator, not as a secret handler.

### Presentation

The viewport is mobile-first 9:16. It uses the æ house style: gold-on-void, neural mesh, `>_æ:` prompt grammar, copyable install command, and inline dynamic notation.
