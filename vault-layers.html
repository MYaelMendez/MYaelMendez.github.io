1 Encryption at Rest AES-256-GCM
Every entry is encrypted with a fresh 96-bit nonce. The GCM tag authenticates both the ciphertext and the entry name — a tampered or renamed entry fails closed rather than decrypting to garbage.
AES-256-GCM AEAD per-entry nonce name binding (AAD)
2 Key Derivation KDF
The passphrase is never stored. It is stretched into a 256-bit key via scrypt (N=2^15, r=8, p=1) or PBKDF2 (600k iterations). A wrong passphrase fails closed — the check sentinel catches it before any decryption is attempted.
scrypt (Python v1) PBKDF2 (Web v2) auto-detect brute-force resistant
3 Custody LOCAL-ONLY
The vault file lives at C:\æ\secrets\privateclient\privateclient.væult — git-ignored, encrypted at rest. The plaintext never touches disk, the transcript, or a remote URL. Zero cloud custody.
C:\æ\secrets\ git-ignored atomic writes 0600 permissions
4 QR Air-Gap NO NETWORK
The QR carries the sealed envelope (name + nonce + ciphertext), never plaintext. A photographed or shoulder-surfed QR is useless without the passphrase. Physically isolated transfer — no packet sniffing, no MITM, no DNS hijack.
VAEULT1: prefix sealed blob 0 plaintext tamper-evident
5 Broker +æ://secrets
The +æ://secrets broker is the only thing that moves a secret from disk into an agent. It never uploads, never echoes raw values, never touches cloud. Resolution: env → bridge → væult → refuse.
+æ://secrets get masked stdout secret_value in dict refuses when empty
6 Agent Compartmentalization PER-AGENT
Each agent receives only the secrets it needs. One QR = one secret = one agent. No shared filesystem, no network, no cloud sync between agents. Need-to-know at the physical level.
one QR = one secret per-agent vault no cross-agent leak
7 Physical Presence HUMAN-IN-THE-LOOP
Sensitive operations require a QR scan — proof that someone is sitting in front of the machine. This prevents unauthorized remote execution, automated attacks that have secrets but no physical access, and "set it and forget it" agent runs.
QR scan = human present no remote execution no automated sensitive ops
