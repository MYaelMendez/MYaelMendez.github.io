Choose the task mode from the request:

| Mode | Concrete result |
|---|---|
| Inspect | Verified repository, workflow, runtime, and access inventory |
| Prepare | Reviewable action plan, workflow changes, and completion checks |
| Run | Authorized native execution with a correlated run or operation ID |
| Diagnose | Evidence from failing steps and a bounded repair |

Infer the appropriate mode and continue the lifecycle as authorized. Do not force every request through all modes. A read-only request remains read-only; preparing a workflow is not dispatching it. Resume existing plans and runs rather than creating duplicate actions.
