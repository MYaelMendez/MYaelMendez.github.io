# >_æ://GOVERNED_ROBOT

## Thesis
human://root ≡ root://human. One viewport. Every action receipted.

## Scope
- 9:16 terminal frame, black void, JetBrains Mono, neon æ palette.
- Real Asimov-1 head GLB (`neck_pitch_link`), upright on its neck mount.
- The **semicircular front faceplate is the only viewport**.
- Default finish: reflective mirror arch. LED/content programs render on demand.
- Camera port is an open hole at lower centre, never painted.
- No side displays, no crown display, no accessory rails or HUD clutter.
- Authority chain: HUMAN://ROOT → æ://POLICY → robot://BODY → RECEIPT.
- Programs kept to the point: MIRROR / FACE / TEXT / OFF.

## Receipts
SHA-256 hash chain `{seq, ts, actor, action, meta, prev, hash}`, persisted to localStorage. Boot, program changes, state cycles, and orbit gestures are receipted.

## Files
- `index.html`, `main.css`, `main.js`
- `modules/authority.js` — ledger
- `modules/mask.js` — canvas viewport engine (arch aperture + camera cutout)
- `modules/scene.js` — Three.js shell, mirror, LED layer, camera
- `assets/` — local GLB + vendor runtime only
