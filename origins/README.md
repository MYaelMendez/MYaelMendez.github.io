# Glass Origins · 0.2.0

Twelve-second procedural WebGL/SVG origin story: a conversation's three æ dots unfold into craft, explore within the glass boundary, and return. No image assets or third-party scripts are required. `index.html` is also a standalone downloadable file.

The inspector uses the embedded public descriptor for portable `file:` viewing. Under HTTP(S), it fetches the adjacent `environment.json`, validates the identity/version/deny-by-default boundary, and requires exact semantic agreement with the embedded snapshot. A failed or mismatched descriptor produces an explicit unresolved state, not a successful inspection.

This is an introduction and read-only discovery bridge. It does not execute agents, authenticate a principal, transfer sessions, or connect Codex, OpenClaw, or Hermes-agent. References to ae-cockpit tests are scoped to that separate implementation. The visual approval scene is explanatory, not an authorization control.

The existing homebase, chat, and OpenAI Site retain distinct roles. No home page replacement, compulsory handoff, merge, or deployment is part of this source change. The original OpenAI Site has not been edited and has not been verified to consume this descriptor.

Preview using your host's supported static preview and open `/origins/`. The portable file also opens directly. Run `node --test tests/glass-origins.test.cjs` from the repository root for production-validator, animation-geometry, loop-periodicity, and JavaScript syntax checks. These are Node tests, not browser tests or shader execution tests.
