03 · OpenSourceWare

¿Listo para ver cómo funciona?

El código abierto permite leer, ejecutar, cambiar y compartir código según su licencia. Aquí conservamos los instrumentos y enlaces originales para aprender paso a paso.

Las cuatro acciones: leer, ejecutar, cambiar, contribuir
  1. READ: README, LICENSE, source.
  2. RUN: install and run tests.
  3. CHANGE: make a small reversible change.
  4. CONTRIBUTE: report a reproducible issue or propose a change.

Glosario: OSW, tiny*, recibos, laboratorio, puertas

#OSW: open sourceware. tiny*: one capability per small package. Receipt: evidence of a run; cryptographic verification requires additional checks. væult: encrypted secrets tooling. Laboratory: experiments and measurements. Doors: navigation to instruments, films, domains and archive.
