# æPICO Capability Discovery

Status: review-only design, not deployed.

Capability-first emoji navigation inside a 9:16 human-owned environment.

## v0.1 scope

- Search intents and browse emoji capability categories.
- Distinguish installed plugins, public catalog candidates, and unverified concept slots.
- Use official plugin entry points for connection and permission review.
- Never claim a plugin is installed based only on an emoji or public listing.
- Human confirmation before payment, publishing, or account changes.
- Witness labels proposals and simulations separately from verified actions.
- The æQR³ hierarchy links root environment, æPICO module, and capability manifests.

## Initial verified account snapshot

Shopify and Stripe were reported installed by plugin discovery on 2026-10-15. This is not a live connection test and grants no transaction authority. Other emoji tiles are design slots until checked.

## Implementation acceptance

Accessible mobile 9:16 UI, text search, category/status filters, non-executing intent handoff, no embedded credentials, documented sources and statuses, no automatic plugin execution.

Invariant: Context may propagate; authority does not.
