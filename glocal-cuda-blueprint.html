PITFALLSAVOID
Zombie endpoint — an old vps_node holding :3050 serves stale code and masks your fixes. Kill by PID (taskkill) before re-probing. The while true wrapper restarts on death; a leftover orphan does not.
GPU context contention — two processes can't both own the CUDA context. One endpoint per GPU. Foreground test + background server collide → list index out of range.
Cloud cost creep — a forgotten pod is the only recurring bill here. Destroy on idle; the route slot stays codemode-ready with no spend.
Keys on the pod — never bake a token into the image. The pod resolves secrets at runtime via +æ://secrets broker (or an env inject), same as Victus.
Treat the droplet as brain, not hands — it has no GPU; rtx3050://ready is an advertisement. Real silicon is Victus/cloud behind the tunnel.
C:\ae vs C:\æ — unicode path is real. Latin silently fails (same trap as secrets).
