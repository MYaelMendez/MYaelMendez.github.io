# mobility.foundation

`mobility.foundation/mobility/` is the canonical public address for Asimov Agent
mobility and the `æLOCOMOTION` package.

The static page is published from the GitHub Pages repository under `mobility/`
and is reachable directly at the raw fallback URL:

- canonical: https://mobility.foundation/mobility/
- fallback: https://myaelmendez.github.io/mobility/
- raw: https://raw.githubusercontent.com/MYaelMendez/MYaelMendez.github.io/gh-pages/mobility/index.html

The apex domain currently redirects to the root of the GitHub Pages site. To
serve the `/mobility/` path at the custom domain, the Pages source and custom
domain mapping must be configured in GitHub repository settings. Until then,
raw URLs are the verifiable delivery path.
