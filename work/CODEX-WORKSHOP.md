# Codex workshop entry

The root and /work/ pages link to the existing authenticated Studio Codex workshop. The local text-tool viewports remain local; a link does not bind a remote runtime or transfer their state.

The workshop implements saved task preparation, payload review, guarded session creation, status/command inspection, cancellation requests and evidence export using the OpenAI Agents API. The server retains a required spending limit and does not retry without it. Provider rejection of this field currently blocks verified sandbox execution. The homepage therefore distinguishes available preparation from unverified execution.

The link includes no local intent, source, profile or grant. GitHub access and repository operations are separate capabilities.
