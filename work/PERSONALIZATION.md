# OSW personalization

The homepage and /work/ offer Make it mine: a workspace name, purpose and optional domain label. These labels are saved only in the current browser. A domain label does not connect DNS or prove ownership. Personalization never authenticates a human, connects a provider or grants execution authority.

Forget personalization removes this profile without clearing the open work session. Show portable profile presents copyable JSON with no credentials, verified-domain claim or runtime grants. The existing task and evidence lifecycle remains separate. Reloading still clears task work; only appearance and personalization persist.

Local validation: 20 tests passed, including profile bounds, invalid domain input, malformed/unavailable storage and the existing workspace lifecycle. Native CI includes tests/personalize.test.mjs. Browser and publication verification are separate release checks.
