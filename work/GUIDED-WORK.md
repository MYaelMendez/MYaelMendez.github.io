# A responsive first contribution

The homepage and /work/ now offer editable starting material, an immediate intent/brief preview, a state-derived next-step guide and three contribution navigation tiles. The guide points to the real existing controls; it neither approves nor executes a task automatically. Tiles become returned only when the local workspace actually returns a result. The activity line names an actual local event, not simulated agent presence.

Existing personalization, themes, explicit context selection, revision-bound approval, revocation, timeouts, local receipts and optional discovery requests remain separate. Input text is rendered with textContent. No new provider request, authenticated identity, cross-host state persistence or external agent is introduced.

Verification: 22 local tests passed, covering the full guided lifecycle and expired approval alongside existing workspace tests. Native CI runs the same checks. Browser behavior and deployment must be verified separately. The existing preserved origin and peer Site are unchanged.
