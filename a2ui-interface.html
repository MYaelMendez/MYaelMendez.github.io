Welcome to A2UI

This card was generated by an AI agent using declarative JSON.

🔒 Security First

A2UI is a declarative data format, not executable code. Your client maintains a catalog of trusted, pre-approved UI components. Agents can only request to render components from that catalog.

"type": "card" // must exist in registry "props": { ... } // validated against schema
🧠 LLM-Friendly Format

UI represented as flat list of components with ID references. Easy for LLMs to generate incrementally, enabling progressive rendering and responsive UX.

"components": [ { "id": "header-1", "type": "text" }, { "id": "form-1", "parent": "header-1" } ]
🌐 Framework Agnostic

Same A2UI JSON renders on multiple clients: Web Components, Flutter widgets, React, SwiftUI, or MÆCH Native. The agent sends structure, clients render natively.

Lit → Web Components Flutter → Material Widgets Angular → Angular Components MÆCH → Native Territorial
⚡ MÆCH Integration

A2UI powers MÆCH territorial programming. Agents generate UI with QR-addressable coordinates. Each component maps to x₀y₀z₀ machine context.

"mech": { "coord": "x₀y₀z₄", "territorial": true, "qr_address": "æææ:///a2ui/demo" }
