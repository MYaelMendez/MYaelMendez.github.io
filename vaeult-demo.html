An unsigned card is a bearer token — a photograph of someone
  else's card dispatches the same action. A signed card binds verb, target,
  subject, and expiry.

5 · Three agents, one shared repo

  
Agents that push independently collide; a commit can land on a
  branch nobody watches. The push is a unit of work, so it gets a board task,
  and the task is the lock. Watch them queue.

  


  
6 · What the gate does under real conditions

  
Rotation, blur, glare, perspective, occlusion, compression.
  The gate agrees with the decoders in all 21 degraded cases — the one

  genuinely cannot read it.
